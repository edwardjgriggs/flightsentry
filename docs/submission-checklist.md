## Strong optional supporting evidence

The published checklist does not require Bob screenshots or exported session links. These remain useful supporting evidence:

- Representative IBM Bob workspace or session screenshot
- Prompt and response excerpt showing a material implementation task
- File-change or diff reference tied to the session
- Test output produced during the Bob-led workflow
- Public deployment link
- Validation record and independent cybersecurity review summary
- Data and model cards
- Dataset attribution and license
